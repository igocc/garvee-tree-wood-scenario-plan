流程总览

一、端到端总流程与红线

实线按阶段推进；虚线表示缺证、冲突或验收不通过时的精准回退目标。

四条流程红线（全流程适用）

红线项硬性判定标准禁止行为正确处置
可售卖定义硬性判定标准目标市场 且 目标渠道已上架 且 当前分支适用，三者缺一不可禁止行为仅凭目录命中、异市场/异渠道链接或历史链接直接推荐正确处置在架与适用分别留证；缺任一关进待核清单或商机卡
读数口径隔离硬性判定标准关键词月估算、AI 主题估值、问句附带估值、Peec 运行数属不同层级禁止行为跨层相加、跨模型求和、对冲突值取均值、把估值当真实流量正确处置按原始层级分列标注；同键异值双留来源并暂停该数值比较
两类提示词区分硬性判定标准研究提示词（步骤 5/6 收录或监测）≠ 生成任务卡（步骤 11 约束产出）禁止行为把模型回答当客观事实，或把内部配置题直接当作用户搜索需求正确处置模型说法须回查引用原文或商品资料；页面只采信可追溯原词/原问句
发布授权门禁硬性判定标准无该版本与目标的明确发布授权时，流程止于步骤 14 本地交接禁止行为默认外发、未回读即对外确认、状态未知时整包重发正确处置回读目标位版本、文件清单与指纹；异常先核查外部实际状态

核心术语速查（一句话看懂专业名词）

术语一句话释义所在步骤
种子词（Seed）一句话释义从品运初稿提炼的产品核心词、当地别称或任务词，用作 Semrush 扩词起点所在步骤1–2
归一键 / 去重键一句话释义归一键按语言统一大小写和空格；去重键=归一键+市场+窗口+口径，用于同口径去重所在步骤3
同键异值一句话释义同一去重键出现多个不同数值时，双留来源进冲突表，不取均值、暂停该数值比较所在步骤3
八维标注与主意图一句话释义按核心词/场景/动作/材料/配件/属性适配/比较选购/用户问题多选标注，另定唯一主意图所在步骤4
AI Topic / Prompt一句话释义Semrush 中 Topic 为主题聚合估值，Prompt 为具体原问句；两者数值分层，不可相加所在步骤5
配置题 / 运行数一句话释义Peec 中团队配置的监测问题（promptId）及各次回答记录（runId），仅作观察线索，非流量所在步骤6
观察 / 推断 / 选择一句话释义原文观察为词句字面；语义推断为条件推测；设计选择为页面落点决定，三者分栏不混写所在步骤7
指定基线一句话释义旧版方案互相冲突时，由范围负责人书面指定的唯一比对起点版本所在步骤1、8
反事实检验一句话释义假设条件改变后，检验下一动作、适用商品、操作前提是否实质变化；均不变则不拆分支所在步骤8
整套含件 vs 单件一句话释义随主机打包附带的部件（不可单买）与独立上架售卖的备件/配件，核品时必须分开登记所在步骤9–10
可售卖 vs 限域未命中一句话释义可售卖须满足目标市场+渠道已上架且适用；限域未命中指仅部分目录未查到，进待核所在步骤10
served 型号 / 指纹一句话释义served 型号指模型复审时服务端实际响应版本；指纹指文件校验哈希或版本号，用于核对一致所在步骤14–15
分步执行

二、分阶段执行结构与决策树

1. 阶段一：立项与数据采集（步骤 1–6）

步骤与角色输入核心操作判断关口与产出回退条件
1　品运立项输入品运初稿、品类任务、目标市场与渠道、现有页面核心操作拆出范围单、种子词表、待查问题三清单；标明已确认、待核、假设与指定基线判断关口与产出说清市场、渠道、用户与页面决策目标 → 三清单与基线回退条件范围含混先确认；无权限先做获准部分
2　研究采集输入范围单、种子词、工具权限核心操作Keyword Magic Tool 选目标国家库 → 逐词查 → All Keywords → Export；记日期、窗口与截断判断关口与产出资料可定位，区分完整/部分/空表/不可读 → 来源清单与原表回退条件缺表先登记覆盖缺口，不擅自推断全量
3　研究清洗输入原始词表、来源清单核心操作文本格式导入防丢前导零；建立归一键与去重键；执行对账公式并分离冲突数值判断关口与产出同键同值仅引 1 次，异值进冲突表 → 有效词表、重复映射、冲突清单回退条件原值冲突暂停数值比较，原词仍入语义审读
4　研究+品运选词输入有效词表、长尾原文核心操作保复合词/型号/否定/范围分词；标八维标签与主意图；对象×动作×目标聚类并抽查四类边界词判断关口与产出说清谁在做什么及什么条件改变选路 → 带源行词簇、排除记录、场景词表回退条件过宽拆对象动作，过窄扩当地别称；纯品名继续挖动作词
5　研究查 AI 问句输入入选场景词、待答问题核心操作核实入口为 AI Prompt Research（非 SEO Topic Research）；每次 1 词 Analyze；分导 Topic 与 Prompt 表判断关口与产出问句挂回对应主题且关联选择分支 → 主题-问句对应表、待追问清单回退条件未命中扩同义词；无导出功能时逐页摘录并标部分覆盖
6　研究按需监测输入未答清问题、Peec 权限核心操作标注题目来源（原句/改写/新增）；Prompts→Add 设国家/主题/角色；Chats 核答；Project 导出后按 promptId+created 筛窗判断关口与产出观察能改变页面回答，区分配置题与逐次运行 → 问答对照、引用核查单回退条件仅历史窗口须注明；无权限或不影响决策直接跳过并记因

工具配置与可替换矩阵

步骤默认工具与入口必留原始字段可替换前提严禁操作
2默认工具与入口Semrush Keyword Magic Tool（目标国家库 → All Keywords）必留原始字段Keyword、Volume、Intent 及全原列可替换前提同市场同口径词库工具，须登记入口与窗口严禁操作跨市场混导、丢失源行号或过滤条件
5默认工具与入口Semrush AI Prompt Research（Enter a topic → Analyze）必留原始字段Topic 表：name, prompts_count, volume, volume_trend, intents, topic_id
Prompt 表：prompt, llm, topic_id, topic_name, topic_volume		可替换前提具有主题与原始问句导出的 AI 问答研究工具严禁操作误用 SEO Topic Research、缺 ID 时强行错配
6默认工具与入口Peec AI（Prompts → Chats → Project 导出）必留原始字段promptId、model、user、assistant、created、sources、sourceUrls、citations、mentions可替换前提有国家/角色/模型切片且可导出引用的监测工具严禁操作用全量导出充当当期窗口、把无引用回答当事实

研究台账读数口径与清洗对账（四层隔离）

记录层级唯一键构成数值口径与单位允许用于何种决策
搜索关键词唯一键构成归一词 + 市场 + 窗口 + 口径数值口径与单位该市场估算月搜索量 Volume（零值照录，空值记未提供）允许用于何种决策识别用户表达、核心对象/动作及长尾约束
AI 主题唯一键构成topic_id/核实名称 + 市场 + 时期 + 来源数值口径与单位主题层级 volume（周期未明示写“主题估值，周期未注明”）允许用于何种决策筛选需下钻读取原问句的高相关主题
AI 原问句唯一键构成prompt + topic_id + llm + 批次数值口径与单位topic_volume 标“所附主题/模型估值”，与主题总值分列允许用于何种决策提取选型比较维度、前置条件与待答问题
配置题与回答唯一键构成题：promptId + 版本 + 角色
答：唯一 runId / 运行键		数值口径与单位源无流量估值写“未提供”；题目数与运行次数分别计数允许用于何种决策核查模型覆盖与回答分歧，把缺口转为资料需求
  • 清洗对账公式：输入行数 = 有效行数 + 本次规则排除行数；有完整键的有效行内 重复附加行数 = 有键行数 − 唯一键数；跨簇复用按 证据ID 核重。
  • 八维标注维度：核心词 / 场景 / 动作 / 材料 / 配件 / 属性适配 / 比较选购 / 用户问题（可多选，另配单选主意图及理由）。
  • 四类必抽查样本：头部高频词、低量高约束词、跨簇交叉命中词、边界反例词。

2. 阶段二：场景归并与路径分流（步骤 7–8）

步骤与角色输入核心操作判断关口与产出回退条件
7　研究归并证据卡输入词簇、问句、可用监测、排除记录核心操作并排读原词与问法，写对象/已有状态/目标/动作/限制；严格分列原文观察、语义推断、设计选择及反例判断关口与产出能指出哪段原文改变下一步，购物/比较/信息/服务分开标记 → 场景证据卡、未决问题、建议入口回退条件孤立词或仅模型自述留待核假设；不足拆路就地说明；纯臆测搁置
8　品运+内容定路径输入场景证据卡、指定基线版本核心操作定位旧稿块或表行写差异处置；做反事实检验确定分支；画全进入状态、判据、跳过、未知出口与终点判断关口与产出目标/动作变才独立入口；已有设备跳选购；参数未知给核对+继续阅读 → 路径图、基线差异表回退条件旧稿冲突退步骤 1 定基线；无旧稿标未能比对；争议能力承诺先撤下

分支定义六要素（每条 分支ID 必填）：进入状态 → 选择题与分流判据 → 下一动作 / 可跳步骤 → 适用商品角色 → 参数未知出口 → 完成标志。

3. 阶段三：三关核品与页面搭建（步骤 9–12）

步骤与角色输入核心操作判断关口与产出回退条件
9　品类查目录输入动作、前提、所需功能与约束核心操作按别名/类目/型号/配件检索约定目录，留查询式、源行、SKU、变体，分开整套含件与独立上架件判断关口与产出命中可定位型号，用途可逐项比对 → 动作-目录匹配表回退条件仅有相邻用途转核品；限域未命中写清范围与扩查方向；纯信息路径直入步骤 11
10　品类核在架与适用输入匹配表、商品页、含件清单、说明书核心操作分步核实目录身份 → 目标市场渠道在架链接 → 场景适用参数；行业/安全说法查地域/对象/日期正文判断关口与产出仅上架且适用进推荐；确认未上架且需求成立建商机 → 可售卖表、商机表、待核清单回退条件标清四类待核原因（缺用途/相邻/限域未命中/冲突），回填后重判；期间撤下未证实承诺
11　内容负责人发任务卡输入批准证据卡、路径表、可写商品字段与缺口核心操作指定受众、语言、交付形态、冻结输入、可引用字段、禁写承诺、模块顺序与验收动作判断关口与产出每条关键判断有 证据ID，条件推荐带边界 → 生成任务卡、模块草表回退条件缺输入退回对应卡，剔除无据段落；有据模块可先行
12　内容+设计搭建输入生成任务卡、模块草表核心操作按任务顺序搭建模块；首屏交代起点与结果；选项只问改变选路的条件；校验 5 类起点可达与返回判断关口与产出主入口/已有条件/信息出口/无匹配/返回均通，文案可反查 → 有序模块表、本地可读稿回退条件路径错退步骤 8；交互文案留本步；越权推荐型号退步骤 10

可直接复用的生成任务卡模板（步骤 11）

为〔目标用户、语言〕生成〔页面框架／文案／本地原型〕，帮助用户从〔进入状态〕达到〔任务结果〕。使用基线〔版本〕、证据卡〔ID〕、路径〔ID〕与核品记录〔ID、可写字段〕。先交有序模块表，再按表生成正文。写清进入条件、可跳步骤、选择分支、未知去向和完成标志；内部表关联来源，前端仅呈任务与条件。对〔待核项〕只列核对问题，禁写〔明确禁写承诺〕。按《成品验收单》逐项交付，单列待人工决定事项。

4. 阶段四：验收、交接与授权发布（步骤 13–15）

步骤与角色输入核心操作判断关口与产出回退条件
13　验收核稿输入冻结输入、模块表、本地成品、验收单核心操作回查成品原值、单位与型号；从多起点走通路径；按形态验双格式、离线、窄屏与键盘判断关口与产出必验项均有实测，原值可追，分支可达，未核已隔离 → 被验版本、实测与复测清单回退条件按错误类型精准回退步骤 1/3/5/6/7/8/10/12，修后冻结新版复测
14　项目负责人交接输入通过验收版本、待核单、约定复审要求核心操作分角色移交台账/缺口/任务卡并确认版本；完成约定复审（模型复审记 served 型号、指纹与意见处置）判断关口与产出文件、接收对象、检查范围与复审状态一致 → 本地交接回执、复审回执回退条件型号或指纹无法核对标待核，保留本地可审稿待补录或重审
15　发布负责人（按授权）输入指定产物版本、目标位置、发布授权记录核心操作核可外发范围；按授权发布后从目标位回读版本、文件清单与指纹判断关口与产出实际目标、版本、文件与批准包完全一致 → 发布回执回退条件无授权止于本地；结果未知或回读不符暂停对外确认，先查外部状态再处理
