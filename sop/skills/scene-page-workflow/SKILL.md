# 场景研究与页面搭建

## 1. 先盘点输入与基线

读取用户提供的品运初稿、目标市场与渠道、商品目录、现有页面与可用研究导出，输出一张**材料清单**（文件、版本、覆盖范围与缺口）。若市场、渠道、目标用户或页面决策目标缺失，先写清待确认人；有材料支持的部分先行推进。

参照[《场景研究与页面搭建 SOP》](../../场景研究与页面搭建-SOP.md)的四阶段与流程图执行；每个新品类均须基于其自身范围单与原始导出独立建档。

## 2. 按场景生成或完善流程

**新建流程：** 先输出《范围单》《种子词表》《待查问题》三清单；有可用导出时进入清洗、八维标注与场景归并，缺采集时按 `Semrush KMT → Semrush AI Prompt Research → Peec AI（按需）` 顺序给出采集清单（写清入口、必留列、口径与下一步）。资料齐备后依次补齐场景分支、三关核品与商机、内容落点与页面模块、成品验收。

**完善流程：** 从用户入口逐段走查到完成动作，输出“现状 → 阻塞点 → 建议改动 → 负责人 → 验收动作”对照表（附原稿定位），按是否阻断选路或误导用户排优先级。

每一步必须写清：输入、角色、操作、判断关口、产出与失败回退步骤。区分**研究提示词**（工具收录与监测配置）与**生成任务卡**（约束页面产出）；Peec AI 回答中的关键说法须回查引用原文。

## 3. 三个核心判定关口

1. **是否拆分支：** 仅当用户条件变化导致**下一动作、适用商品或操作前提**实质改变时单立分支，写全“进入状态 → 选择题 → 下一动作/跳过 → 商品角色 → 未知出口 → 完成标志”。
2. **能否推荐商品：** 分别核实目录型号、目标市场与渠道在架链接、当前分支适用性；仅上架且适用可推荐；确认未上架且需求成立建商机卡；范围未覆盖或适配不明进待核清单。
3. **问题放哪：** 改选路放模块旁；同任务直答放 FAQ；多步操作放独立指南；多维对比放博客；缺证据入待核清单。

交付前从页面模块反查原词/原问句与在架适用凭据，并走查待核路径。默认交付本地文档；发布仅在获得该版本与目标的明确授权后执行并回读验证。
