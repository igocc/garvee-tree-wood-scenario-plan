# GARVEE 树木清理与木材利用：场景规划、商品匹配与品类商机

[在线阅读](https://igocc.github.io/garvee-tree-wood-scenario-plan/) · [直接进入商品匹配与商机](https://igocc.github.io/garvee-tree-wood-scenario-plan/#catalog)

本报告围绕清场、薪柴加工与储存、链锯制材三条任务路径，结合归档关键词/提示词与本机商品目录，为页面搭建、既有商品复用和品类研究提供线索。

- 8条需求发现、4个假设用户例子。
- [9页具体构建框架](https://igocc.github.io/garvee-tree-wood-scenario-plan/#framework)，50个图形容器：首屏分栏、条件分支、步骤条、商品卡网格、组件连接、资料页签和问答区。默认显示整页线框，点容器展开说明；支持桌面/手机布局、9页切换、展开全部和4个起点检查示例。
- 构建框架主要依据本轮需求发现和商品目录匹配，飞书归档仅作参考。建议店铺路径尚未上线，框架示意不是实际商店购物流程。
- 21项场景商品角色：14项目录已有候选、3项相邻商品用途待核、4项未确认对应类型/整机。
- 13张品类研究卡：8项新类型待验证、2项补购形态、2项既有商品用途待核、1项兼容资料缺口。

## 资料范围与限制

目录基于归档 `01_SKU_Audit.xlsx` 50,620条记录的名称/类目检索与定向审读；本仓库仅发布报告所引用的选取证据，不发布完整原始目录或数据库。关键词为2026-11-04导出文件，飞书方案为2026-11-12归档；当前报告版本为2026-11-17。

“目录已有候选”不等于当前在售、用途适配或商品齐套；“目录未找到”不等于GARVEE官网当前没有。商品商机卡是核品与需求研究方向，不是立项或收益结论。关键词月搜索量、主题估值、提示词附带主题/模型值及配置监测问法不可相加。

选取商品与需求记录的507个字段已核对来源库及18个原始文件；页面已通过桌面/手机、筛选、7项下载字节一致、离线与打印检查。
